Tekstowa gra RPG zwana BOMBKI autorstwa Mateusza Pawluczuka. Oraz proba
przeniesienia jej na nowoczesne systemy operacyjne wraz z kilkoma
usprawnieniami.

Glowne zmiany w porcie:
- wszystko jest turowe, bez timerow
- poprawione nieco ortografii (w tym "polodnie")
- wygodniejsza nawigacja (poruszanie za pomoca n,s,w,e,u,d)
- pozbycie sie stanu podswiadomosci (mode/unmode)
- odrobinka zmian layoutowych dla czytelnosci
